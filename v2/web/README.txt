JuhudManager V2 - Web Frontend

Folder contents:
- index.html
- assets/css/app.css
- assets/js/config.js
- assets/js/api.js
- assets/js/login.js
- assets/js/registration.js

Installation:
1. Upload the contents of this ZIP into the repository's v2/web/ folder.
2. Preserve the assets/css and assets/js subfolders.
3. Do not upload this folder as v2/web/web/.
4. API_BASE is intentionally empty in assets/js/config.js.
5. Set API_BASE only after the V2 Worker URL is confirmed.

Important:
- This package contains the split login and registration frontend.
- password-setup.html is not included yet; its exact email link format must
  first be confirmed from the backend email delivery implementation.
- No backend, database, migration or deployment changes are included.
- Source has been prepared for repository upload; it has not been tested
  against the live Worker.
